# 🍎 Foodsnap — AI Food Vision Chatbot

## About the Project

Foodsnap is an AI-powered chatbot that analyzes food images and provides estimated nutritional information, including calories, protein, carbohydrates, and fat.

## Features

* 📸 Upload food images.
* 🤖 Analyze food using AI.
* 🥗 Get estimated nutritional information.
* 💬 Chat with an AI assistant.
* 📱 WhatsApp integration, if configured.

## Technologies Used

* Python
* Streamlit
* Google Gemini API
* Twilio API

## How to Run

1. Clone or download this repository.

2. Install the required packages:

   `pip install -r requirements.txt`

3. Configure your API keys in `.streamlit/secrets.toml`.

4. Run the application:

   `streamlit run app.py`

## Security

Keep your API keys and credentials private. Never upload your secrets file to a public repository.

## Project Goal

To make food and nutrition information easier to understand through AI-powered image analysis.
